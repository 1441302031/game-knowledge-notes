SNHE: 结构化神经混合引擎

AI Native 引擎 for HD-2D JRPG — 确定性核心 + AI 内容管线 + 混合渲染

确定性核心为什么必要

  • • HD-2D 的精确美学依赖确定性渲染
  • • 回合制战斗（Break/Boost）必须 100% 可控
  • • 存档/任务系统不能有概率性错误
  • • RAG 注入：LLM 接收结构化 Game State

AI 负责什么

  • • NPC 自由对话（llama.cpp 本地推理）
  • • 像素精灵批量生成（SDXL + LoRA）
  • • 地图布局 + 纹理生成（ControlNet）
  • • 动态支线任务和世界反馈

关键设计决策

  • • 离线批量生产 → 热缓存加速 (非实时 AI)
  • • 纯神经渲染被否决 → 无法维持像素一致性
  • • 三层渲染：3D背景 + 2D精灵 + 后处理
  • • 神经增强层可选 → 保留演进空间

实施阶段

  • • Phase 1: Rust 引擎核心 + 基础渲染 (2-3月)
  • • Phase 2: AI 内容管线 (2-3月)
  • • Phase 3: RPG 游戏系统 (2月)
  • • Phase 4: AI Runtime 集成 (2月)
  • • Phase 5: 打磨发布 (2-3月) ≈ 总计 10-13 月

与传统引擎对比

  • • 内容生产: AI 80% + 人工精修 20%
  • • NPC 对话: LLM 动态 ≠ 固定文本树
  • • 任务系统: 主线预设 + AI 生成支线
  • • 开发效率: 目标 3-5x 加速
  • • 内容量: 理论上无限 (受 LLM 窗口限制)

为什么不是纯神经引擎

  • • GameNGen 适合 Doom 级画面，非 HD-2D
  • • HD-2D 审美 = 精确控制 ≠ 概率分布
  • • 景深/像素色块/镜头角度都需设计
  • • AI Native = AI 成为一等公民 ≠ 替代一切

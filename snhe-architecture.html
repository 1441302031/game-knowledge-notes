SNHE: 结构化神经混合引擎

AI Native 引擎 for HD-2D JRPG — 确定性核心 + AI 内容管线 + 混合渲染

确定性核心为什么必要

  • HD-2D 的精确美学依赖确定性渲染
  • 回合制战斗（Break/Boost）必须 100% 可控
  • 存档/任务系统不能有概率性错误
  • RAG 注入：LLM 接收结构化 Game State 作为上下文

AI 负责什么

  • NPC 自由对话（llama.cpp 本地推理，7B-13B 模型）
  • 像素精灵批量生成（SDXL + HD-2D LoRA 微调）
  • 地图布局 + 纹理生成（ControlNet 精确控制）
  • 动态支线任务和世界反馈
  • AnimateDiff 帧动画生成 + 像素化后处理

混合渲染器架构

  • 3D 场景渲染层：PBR 管线 → 微缩景深 → 体积雾
  • 2D 精灵层：像素精灵、帧动画、粒子特效叠加
  • 神经增强层（可选）：风格迁移、AI 超分、帧间优化
  • 后处理栈：Bloom、Vignette、调色、UI 叠加

离线内容生产管线

策划提示词 → AI 批量生成 → 人工审核精修 → 游戏资产入库
   (SDXL/LLM/ControlNet)   (风格校验/关键场景手调)   (精灵表/场景/对话库)

AI 负责 80% 内容量 → 人工精修 20% 关键内容 → 传统确定性引擎加载。

关键设计决策

为什么不是纯神经引擎

  • GameNGen 适合 Doom 级画面，非 HD-2D
  • HD-2D 审美 = 精确控制 ≠ 概率分布
  • 景深/像素色块/镜头角度都需设计师把控
  • AI Native = AI 成为一等公民 ≠ 替代一切

与传统引擎对比

  • 内容生产: AI 80% + 人工精修 20%
  • NPC 对话: LLM 动态生成 ≠ 固定文本树
  • 任务系统: 主线预设 + AI 生成支线
  • 开发效率: 目标 3-5x 加速
  • 内容量: 理论上无限（受 LLM 窗口限制）

实施阶段

  • Phase 1: Rust 引擎核心 + 基础渲染（2-3 月）
  • Phase 2: AI 内容管线（2-3 月）
  • Phase 3: RPG 游戏系统（2 月）
  • Phase 4: AI Runtime 集成（2 月）
  • Phase 5: 打磨发布（2-3 月）≈ 总计 10-13 月

技术栈

  • 引擎核心：Rust + ECS + 状态机
  • 渲染：bgfx / WGPU 跨平台
  • AI 推理：llama.cpp 本地部署
  • 生成模型：SDXL + LoRA + ControlNet
  • 脚本：Rhai / Lua（策划热更新）
  • 目标平台：PC → Switch → 移动端

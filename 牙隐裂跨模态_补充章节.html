牙隐裂跨模态智能筛查系统 —— 补充章节

本文为「基于跨模态知识蒸馏的口内照片牙隐裂智能筛查系统的研发」申报书的补充内容，包含：团队组成、研究周期、经费预算、纳排标准与样本量依据、参考文献。

六、研究团队组成与分工

6.1 团队总体架构

角色 人数 专业背景要求 核心职责
项目负责人（PI） 1 牙体牙髓病学，副主任医师及以上 项目总体设计、临床方案制定、质量监督、成果产出
临床标注组 3 牙体牙髓科主治医师及以上 显微图像像素级标注、金标准仲裁、临床验证评估
算法研发组 3-4 计算机视觉/医学图像处理，副教授 + 硕/博研究生 教师模型研发、跨模态蒸馏算法、模型优化
工程开发组 1-2 移动端开发/软件工程 模型剪枝量化、移动端SDK封装、筛查APP开发
统计学顾问 1 医学统计学/流行病学 样本量计算、诊断效能评价（ROC/Dice/ICC）、多中心一致性分析

6.2 各角色详细分工

项目负责人（PI）： - 统筹项目进度，制定《牙隐裂口内照片标准化拍摄规范》 - 负责伦理审批（IRB）申报与知情同意书设计 - 协调多中心合作医院，组织前瞻性验证 - 主导论文撰写与成果申报

临床标注组（3人）： - 标注员A/B：独立对显微图像进行像素级裂纹标注（使用LabelMe或ITK-SNAP） - 仲裁专家（高年资主任医师）：对标注分歧进行最终裁定 - 共同参与人机对比研究中的"医生读片"环节

算法研发组（3-4人）： - 教师模型（1人）：基于DeepLabv3+/Swin-UNet在显微图像上训练高精度分割模型 - 跨模态蒸馏（1-2人）：设计输出层+特征层+注意力层多层级蒸馏损失，引入对比学习预对齐 - 弱监督定位（1人）：研发Grad-CAM++/Score-CAM驱动的弱监督热力图生成与抗干扰模块

工程开发组（1-2人）： - 模型压缩：结构化剪枝 + INT8量化，目标模型体积 < 30MB - 移动端部署：封装为Android/iOS SDK（ONNX Runtime / TensorFlow Lite），开发轻量级筛查APP - 实时性优化：单张推理 < 500ms（移动端CPU）

统计学顾问（1人）： - 样本量计算（基于效应量、α=0.05、power=0.80） - 诊断效能指标计算（敏感度、特异度、PPV、NPV、AUC） - 标注一致性评估（Cohen's κ / ICC） - 人机对比研究中的配对检验设计

九、纳入/排除标准与样本量依据

9.1 牙隐裂诊断标准

参考美国牙髓病学会（AAE）《 cracked teeth and vertical root fractures 》指南及 Ellis 分类：

临床诊断依据（满足 ≥2 条）： 1. 咬合痛/咀嚼痛（尤其是咬硬物或特定方向） 2. 冷刺激敏感/疼痛（不可复性） 3. 透照法显示裂纹线（光纤透照下可见纵向/斜向透光中断线） 4. 亚甲蓝染色后显微镜下可见染料渗入裂纹 5. 牙髓电活力测试异常 6. 排除其他病因（龋病、牙周病、牙髓炎无裂纹型、牙折）

9.2 牙隐裂分裂

参照 Ellis 分类（改良版）：

分级 描述 纳入本研究的理由
Ⅰ级 裂纹局限于釉质层，无症状或轻微敏感 ✅ 纳入（早期筛查最有价值）
Ⅱ级 裂纹累及牙本质浅层，可复性牙髓炎 ✅ 纳入
Ⅲ级 裂纹累及牙本质深层，不可复性牙髓炎 ✅ 纳入
Ⅳ级 裂纹延伸至髓腔/髓底 ✅ 纳入
Ⅴ级 牙齿完全纵裂（裂至根分叉以下） ❌ 排除（直接拔除，无需AI筛查）

9.3 图像纳入标准

显微图像： - 放大倍率 ≥ 10×（10-40×均可） - 拍摄范围完整覆盖裂纹区域及周围 ≥ 3mm正常牙体组织 - 焦点清晰，裂纹主体无运动模糊 - 使用亚甲蓝染色后拍摄（辅助裂纹可视化）

口内照片： - 按照《标准化拍摄规范》拍摄（统一角度：90°正位 + 45°侧位，统一光源） - 分辨率 ≥ 1920×1080 - 无反光遮挡裂纹区域（如有局部反光但裂纹区域可见，可纳入） - 无唾液池覆盖裂纹路径

9.4 排除标准

患者/牙齿层面： 1. 全冠修复体覆盖裂纹区域（无法拍摄裂纹） 2. 重度牙周病（松动度 ≥ Ⅱ度，影响拍摄） 3. 广泛龋坏破坏牙冠形态（难以判断裂纹独立影响） 4. 既往牙髓治疗（根管治疗/干髓术等影响影像判断） 5. 根尖片/CBCT已明确提示根折/根裂 6. 妊娠期/哺乳期女性（伦理保护） 7. 未成年患者（需额外监护人同意，增加伦理复杂度，可在后续扩展研究中纳入）

图像层面： 1. 对焦失败、运动模糊严重 2. 口腔软组织（舌/颊/唇）遮挡裂纹区域 ≥ 50% 3. 出血遮挡裂纹

9.5 金标准建立流程

患者就诊 → 临床检查初筛（符合诊断标准 ≥ 2条）
         → 签署知情同意书
         → 口内照片拍摄（标准化规范）
         → 亚甲蓝染色
         → 显微镜拍摄（10-40×）
         → 标注员A独立标注（像素级）
         → 标注员B独立标注（像素级）
         → 计算标注一致性（ICC/Dice）
         → 若ICC < 0.80：仲裁专家介入，逐例讨论
         → 仲裁后标注作为金标准

9.6 样本量计算依据

训练集（配对数据）

基于医学影像分割研究的经验公式：

目标：Dice ≥ 0.75，效应量（effect size）= 0.15（预期学生模型与baseline之间的差异），α = 0.05，power = 0.80

  • 根据 nnU-Net 的经验（Isensee et al., 2021），医学图像分割在小样本下（n=50-100）即可在标注一致性高的数据集上达到稳定性能
  • 考虑 20% 数据剔除率（图像不合格、撤回知情同意等）
  • n ≥ 150 = 120（有效训练）/ 30（预留测试集）

训练/验证/测试划分：按患者级别 5 折交叉验证，外部分割出 30 例作为 hold-out 测试集。

前瞻性验证集

基于诊断试验样本量公式：

目标：敏感度 ≥ 90%（预期敏感度 p = 0.90），允许误差 d = 6%，α = 0.05

$$n = \frac{Z_{\alpha/2}^2 \cdot p(1-p)}{d^2} = \frac{1.96^2 \times 0.90 \times 0.10}{0.06^2} \approx 96$$

向上取整，外部验证集 ≥ 100 例。

人机对比研究

配对设计（同一患者分别由AI和不同年资医生评估）：

目标：AI辅助后低年资医生准确率提升 15%（δ = 15%，σ预估 = 20%），α = 0.05，power = 0.80

$$n = \left( \frac{Z_{\alpha/2} + Z_{\beta}}{\delta / \sigma} \right)^2 = \left( \frac{1.96 + 0.84}{0.15 / 0.20} \right)^2 \approx 56$$

每组招募 ≥ 60 例，分三组（低年资医生 / 低年资医生+AI辅助 / 高年资医生）。
